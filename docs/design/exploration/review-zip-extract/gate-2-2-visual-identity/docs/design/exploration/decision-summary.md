## 2. Comparison — A+B vs C

| Criterion | A+B Clear Companions × Crew Momentum | C Shared Horizon |
| --- | --- | --- |
| **Financial readability** | Strong — calm hero amount, scarce Deep Sea accent, honest labels | Strong **if** atmosphere stays behind metrics; risk if mist/metaphor competes |
| **Social motivation** | Strong — streak-before-feed, roster energy, milestone amber moments | Medium-strong — belonging via shared horizon; quieter crew tempo |
| **Privacy comprehension** | Excellent — Private chip + visible-member labelling fits fintech chrome | Excellent — dual “My path / Our horizon” naming aids scope clarity |
| **Mobile hierarchy** | Clear four-tier stack; proven fintech + social sequencing | One-composition dual readout; distinctive but denser craft |
| **Accessibility (planned WCAG 2.2 AA)** | Straightforward contrast on flat cool paper; status chips icon+text | Must prove mist backgrounds meet contrast; more prototype risk |
| **Distinctiveness** | Hybrid originality (Deep Sea + Honey Amber); watch neobank-generic drift | Higher metaphor distinctiveness; watch decorative/journey cliché |
| **MVP build complexity (design system)** | Lower–medium | Medium–higher (atmosphere + waypoint system) |

---

## 3. Trade-offs

**Choose A+B if** you want the clearest path to trustworthy money UI plus visible crew habit energy, with lower risk to Trust Before Decorations and contrast.

**Choose C if** A+B feels too close to “friendly neobank + feed,” and you want a stronger ownable metaphor for unequal personal targets inside one challenge.

**Hybrid refinement option (still exploratory):** Keep A+B as the product chrome system; borrow C’s dual labelling (“My path” / “Our horizon”) for visible-member totals only — without full atmospheric landscape. Still requires PO call.
